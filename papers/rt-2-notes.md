# RT-2: Vision-Language-Action Models

- 论文机构：Google DeepMind
- 发表时间：2023
- 链接：https://arxiv.org/abs/2307.15818

## 一句话总结

RT-2 把视觉语言模型进一步训练成视觉语言动作模型。它将机器人动作离散化成 token，和文本 token 一起建模，使模型既能理解图像和语言指令，也能直接输出机器人动作。

## 解决的问题

传统机器人策略模型泛化能力弱。模型通常只在有限机器人数据上训练，换一个物体、背景、环境或任务描述就可能失败。

RT-2 的核心思路是借助大规模互联网图文数据中学到的语义常识，再通过机器人数据进行 co-fine-tuning，让模型把视觉语言理解能力迁移到机器人控制任务中。

## 核心方法

RT-2 的训练流程可以理解为：

1. 选择一个已有的大规模 VLM。
2. 将机器人动作离散化，转成 action token。
3. 将图像、语言指令和 action token 放在同一个序列建模框架中。
4. 使用互联网图文数据和机器人轨迹数据联合微调。
5. 推理时输入图像和任务指令，模型直接输出动作 token，再映射回机器人动作。

## 关键结论

- 在 Language Table benchmark 上，RT-2 超过此前 SOTA，论文报告结果约为 90% vs 77%。
- 相比 RT-1，RT-2 在未见过的物体、背景、环境等泛化任务上有明显提升。
- 基于更强 VLM 的 PaLI-X-55B 版本整体表现优于 PaLM-E-12B 版本。

## 对数据工程的启发

RT-2 的提升不是只来自模型结构，而是来自大规模、多样化、高质量数据的组合。对具身智能数据工程来说，关键问题包括：

- 机器人轨迹数据是否足够多样，能覆盖物体、场景、指令和动作变化。
- 语言指令是否规范，是否和真实动作轨迹对齐。
- 动作离散化后是否保留足够控制精度。
- 不同来源机器人数据的 observation / action 空间如何统一。
- 数据质量问题会直接影响 VLA 模型的泛化能力。

## 后续需要补的问题

- RT-2 中 action token 的 256 bin 离散化细节。
- co-fine-tuning 中互联网数据和机器人数据的比例。
- RT-2 与 RT-1 在数据格式和训练目标上的差异。
- 这类 VLA 模型对 Open X-Embodiment 这类统一数据集的依赖程度。
